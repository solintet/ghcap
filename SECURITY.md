# Security / セキュリティ

## English

Please report security-sensitive issues privately through GitHub's security reporting features, if available, rather than publishing secrets in public issues. Avoid sharing tokens, signing keys, password material or private repository content. ghcap uses external Git, GitHub CLI and (where configured) GnuPG; keep these tools updated. Source distribution is not a claim that every platform has been security-audited. Before publishing a release, verify the source revision, package digests and documented platform tests.

## 日本語

機密性の高い脆弱性は、利用可能であればGitHubの非公開セキュリティ報告機能から報告してください。公開Issueにトークン・秘密鍵・パスワード・非公開リポジトリの内容を書かないでください。ghcapはGit・GitHub CLI・必要に応じてGnuPGを利用するため、それぞれの更新も重要です。ソース配布は全プラットフォームのセキュリティ監査完了を意味しません。公開前にソースCommit、配布物のダイジェスト、対象OSでの検証結果を確認してください。
