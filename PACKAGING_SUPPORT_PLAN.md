# Packaging support / 配布形式

## English

The Actions matrix targets Linux x86_64, Windows x64, macOS Intel and macOS Apple Silicon. Linux output attempts tar.gz, deb, rpm, pkg.tar.zst and AppImage packaging. These are build recipes, not a promise that every format has passed on every system. External GitHub CLI requirements remain relevant to installed packages.

## 日本語

ActionsはLinux x86_64、Windows x64、macOS Intel、macOS Apple Siliconを対象とします。Linuxではtar.gz、deb、rpm、pkg.tar.zst、AppImage形式の作成を試みます。これはビルド定義であり、すべての環境で検証済みという保証ではありません。パッケージ導入後もGitHub CLIの互換性条件があります。
