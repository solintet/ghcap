# Distribution formats / 配布形式

| Platform / OS | Format / 形式 |
|---|---|
| Linux x86_64 | .tar.gz / .deb / .rpm / .pkg.tar.zst / .AppImage |
| Windows x64 | .exe / .zip |
| macOS Intel | .tar.gz |
| macOS Apple Silicon | .tar.gz |

## English

Individual formats may need system libraries, compatible GitHub CLI and Git. The exact file list is checked before publication. Refer to each release's Assets and SHA256SUMS; artifact presence alone does not prove compatibility with every OS distribution.

## 日本語

形式によってはシステムライブラリ、互換版GitHub CLI、Gitが必要です。公開前に成果物一覧を検証します。各ReleaseのAssetsとSHA256SUMSを確認してください。ファイルが存在するだけではすべてのOS・ディストリビューションでの動作を保証しません。
