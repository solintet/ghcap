# winget metadata / wingetのメタデータ

## English

This folder contains release manifest support scripts/metadata. A generated manifest is not automatically accepted by the official winget repository. Verify the asset URL and its SHA-256 after the corresponding Release is published, then submit the manifest through the winget package contribution process.

## 日本語

本フォルダにはwinget用マニフェストの準備資料があります。生成したマニフェストがそのまま公式wingetリポジトリで公開されるわけではありません。Release公開後にAssetsのURLとSHA-256を確認し、wingetのパッケージ提出手順に従ってください。
