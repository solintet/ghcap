# winget manifest output

The version, locale, and installer YAML files are generated by `packaging/generate-package-manifests.sh` after the Windows portable ZIP exists. Set `GITHUB_REPOSITORY` to the public release repository and optionally set `WINGET_PACKAGE_ID` to the package identifier you intend to submit. Confirm the identifier is available and validate the manifests with winget tooling before submitting them to Microsoft's community repository.
